Based on `.agents/skills/webapp-testing/SKILL.md`

## Testing Principles
- Discover and test everything.
- Test user behavior, avoid testing implementation internals.
- Wait for elements deterministically, avoid arbitrary sleeps.
- Verify clean state before and after transitions.
- Stress boundary conditions: rapid key presses, interruption of animations, rapid click bursts, overflow cleanup.
