# Web App Testing (Local Copy for challenger_m1_r2)

> Discover and test everything. Leave no route untested.

## Core Methodology
- E2E Test Principles: user behavior over implementation, stable selectors, clean state, robust assertions with auto-wait.
- Visual and stress testing: Multi-viewport validation, trace viewer, failure diagnostics, regression gates.
- Independent verification: Execute tests directly, capture stdout/stderr, evaluate exit codes and empirical logs.
