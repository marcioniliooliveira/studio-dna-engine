# GlassIcons

> **Category**: Ícones & Micro-visuals  
> **Source**: [https://reactbits.dev/](https://reactbits.dev/)

Icon set styled with frosted glass blur.

---

## 📦 Arquivos Extraídos

| Arquivo | Descrição |
| --- | --- |
| `GlassIcons.tsx` | Componente pronto em React + TypeScript + Tailwind CSS |
| `GlassIcons.jsx` | Versão JavaScript + Tailwind |
| `GlassIcons.css` | Folha de estilos CSS puro auxiliar |
| `GlassIconsDemo.jsx` | Exemplo de uso prático e demo com estado |
| `registry.json` | Especificação completa shadcn / jsrepo com metadados |

---

## 🚀 Dependências Necessárias

```bash
npm install framer-motion lucide-react clsx tailwind-merge
```

---

## 💡 Como Usar

Veja o arquivo [`GlassIconsDemo.jsx`](./GlassIconsDemo.jsx) para o exemplo completo de implementação com estados, props e customizações.

```tsx
import GlassIcons from './GlassIcons';

export default function Example() {
  return (
    <div className="p-8 flex items-center justify-center">
      <GlassIcons />
    </div>
  );
}
```
