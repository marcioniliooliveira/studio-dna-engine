# PulseHeart

> **Category**: Ícones & Micro-visuals  
> **Source**: [https://reactbits.dev/](https://reactbits.dev/)

Like button that contracts to a dot, flips colour at its smallest frame and pulses back while the count swaps one glyph.

---

## 📦 Arquivos Extraídos

| Arquivo | Descrição |
| --- | --- |

## 🚀 Dependências Necessárias

```bash
npm install @hugeicons/core-free-icons@^4.3.3
```

---

## 💡 Como Usar

Veja o arquivo [`PulseHeartDemo.jsx`](./PulseHeartDemo.jsx) para o exemplo completo de implementação com estados, props e customizações.

```tsx
import PulseHeart from './PulseHeart';

export default function Example() {
  return (
    <div className="p-8 flex items-center justify-center">
      <PulseHeart />
    </div>
  );
}
```
