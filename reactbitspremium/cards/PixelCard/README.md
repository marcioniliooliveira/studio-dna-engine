# PixelCard

> **Category**: Cards Sofisticados & Elegantes  
> **Source**: [https://reactbits.dev/](https://reactbits.dev/)

Card content revealed through pixel expansion transition.

---

## 📦 Arquivos Extraídos

| Arquivo | Descrição |
| --- | --- |
| `PixelCard.tsx` | Componente pronto em React + TypeScript + Tailwind CSS |
| `PixelCard.jsx` | Versão JavaScript + Tailwind |
| `PixelCard.css` | Folha de estilos CSS puro auxiliar |
| `PixelCardDemo.jsx` | Exemplo de uso prático e demo com estado |
| `registry.json` | Especificação completa shadcn / jsrepo com metadados |

---

## 🚀 Dependências Necessárias

```bash
npm install framer-motion lucide-react clsx tailwind-merge
```

---

## 💡 Como Usar

Veja o arquivo [`PixelCardDemo.jsx`](./PixelCardDemo.jsx) para o exemplo completo de implementação com estados, props e customizações.

```tsx
import PixelCard from './PixelCard';

export default function Example() {
  return (
    <div className="p-8 flex items-center justify-center">
      <PixelCard />
    </div>
  );
}
```
