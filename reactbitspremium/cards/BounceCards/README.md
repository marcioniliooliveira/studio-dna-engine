# BounceCards

> **Category**: Cards Sofisticados & Elegantes  
> **Source**: [https://reactbits.dev/](https://reactbits.dev/)

Cards bounce that bounce in on mount.

---

## 📦 Arquivos Extraídos

| Arquivo | Descrição |
| --- | --- |
| `BounceCards.tsx` | Componente pronto em React + TypeScript + Tailwind CSS |
| `BounceCards.jsx` | Versão JavaScript + Tailwind |
| `BounceCards.css` | Folha de estilos CSS puro auxiliar |
| `BounceCardsDemo.jsx` | Exemplo de uso prático e demo com estado |
| `registry.json` | Especificação completa shadcn / jsrepo com metadados |

---

## 🚀 Dependências Necessárias

```bash
npm install gsap@^3.13.0
```

---

## 💡 Como Usar

Veja o arquivo [`BounceCardsDemo.jsx`](./BounceCardsDemo.jsx) para o exemplo completo de implementação com estados, props e customizações.

```tsx
import BounceCards from './BounceCards';

export default function Example() {
  return (
    <div className="p-8 flex items-center justify-center">
      <BounceCards />
    </div>
  );
}
```
