# ReflectiveCard

> **Category**: Cards Sofisticados & Elegantes  
> **Source**: [https://reactbits.dev/](https://reactbits.dev/)

Card with dynamic webcam reflection and glare effects that respond to cursor movement.

---

## 📦 Arquivos Extraídos

| Arquivo | Descrição |
| --- | --- |
| `ReflectiveCard.tsx` | Componente pronto em React + TypeScript + Tailwind CSS |
| `ReflectiveCard.jsx` | Versão JavaScript + Tailwind |
| `ReflectiveCard.css` | Folha de estilos CSS puro auxiliar |
| `ReflectiveCardDemo.jsx` | Exemplo de uso prático e demo com estado |
| `registry.json` | Especificação completa shadcn / jsrepo com metadados |

---

## 🚀 Dependências Necessárias

```bash
npm install lucide-react@^0.542.0
```

---

## 💡 Como Usar

Veja o arquivo [`ReflectiveCardDemo.jsx`](./ReflectiveCardDemo.jsx) para o exemplo completo de implementação com estados, props e customizações.

```tsx
import ReflectiveCard from './ReflectiveCard';

export default function Example() {
  return (
    <div className="p-8 flex items-center justify-center">
      <ReflectiveCard />
    </div>
  );
}
```
