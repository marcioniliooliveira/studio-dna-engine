# TiltedCard

> **Category**: Cards Sofisticados & Elegantes  
> **Source**: [https://reactbits.dev/](https://reactbits.dev/)

3D perspective tilt card reacting to pointer.

---

## 📦 Arquivos Extraídos

| Arquivo | Descrição |
| --- | --- |
| `TiltedCard.tsx` | Componente pronto em React + TypeScript + Tailwind CSS |
| `TiltedCard.jsx` | Versão JavaScript + Tailwind |
| `TiltedCard.css` | Folha de estilos CSS puro auxiliar |
| `TiltedCardDemo.jsx` | Exemplo de uso prático e demo com estado |
| `registry.json` | Especificação completa shadcn / jsrepo com metadados |

---

## 🚀 Dependências Necessárias

```bash
npm install motion@^12.23.12
```

---

## 💡 Como Usar

Veja o arquivo [`TiltedCardDemo.jsx`](./TiltedCardDemo.jsx) para o exemplo completo de implementação com estados, props e customizações.

```tsx
import TiltedCard from './TiltedCard';

export default function Example() {
  return (
    <div className="p-8 flex items-center justify-center">
      <TiltedCard />
    </div>
  );
}
```
