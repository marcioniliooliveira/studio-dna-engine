# ProfileCard

> **Category**: Cards Sofisticados & Elegantes  
> **Source**: [https://reactbits.dev/](https://reactbits.dev/)

Animated profile card glare with 3D hover effect.

---

## 📦 Arquivos Extraídos

| Arquivo | Descrição |
| --- | --- |
| `ProfileCard.tsx` | Componente pronto em React + TypeScript + Tailwind CSS |
| `ProfileCard.jsx` | Versão JavaScript + Tailwind |
| `ProfileCard.css` | Folha de estilos CSS puro auxiliar |
| `ProfileCardDemo.jsx` | Exemplo de uso prático e demo com estado |
| `registry.json` | Especificação completa shadcn / jsrepo com metadados |

---

## 🚀 Dependências Necessárias

```bash
npm install framer-motion lucide-react clsx tailwind-merge
```

---

## 💡 Como Usar

Veja o arquivo [`ProfileCardDemo.jsx`](./ProfileCardDemo.jsx) para o exemplo completo de implementação com estados, props e customizações.

```tsx
import ProfileCard from './ProfileCard';

export default function Example() {
  return (
    <div className="p-8 flex items-center justify-center">
      <ProfileCard />
    </div>
  );
}
```
