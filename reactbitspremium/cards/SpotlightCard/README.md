# SpotlightCard

> **Category**: Cards Sofisticados & Elegantes  
> **Source**: [https://reactbits.dev/](https://reactbits.dev/)

Dynamic spotlight follows cursor casting gradient illumination.

---

## 📦 Arquivos Extraídos

| Arquivo | Descrição |
| --- | --- |
| `SpotlightCard.tsx` | Componente pronto em React + TypeScript + Tailwind CSS |
| `SpotlightCard.jsx` | Versão JavaScript + Tailwind |
| `SpotlightCard.css` | Folha de estilos CSS puro auxiliar |
| `SpotlightCardDemo.jsx` | Exemplo de uso prático e demo com estado |
| `registry.json` | Especificação completa shadcn / jsrepo com metadados |

---

## 🚀 Dependências Necessárias

```bash
npm install framer-motion lucide-react clsx tailwind-merge
```

---

## 💡 Como Usar

Veja o arquivo [`SpotlightCardDemo.jsx`](./SpotlightCardDemo.jsx) para o exemplo completo de implementação com estados, props e customizações.

```tsx
import SpotlightCard from './SpotlightCard';

export default function Example() {
  return (
    <div className="p-8 flex items-center justify-center">
      <SpotlightCard />
    </div>
  );
}
```
