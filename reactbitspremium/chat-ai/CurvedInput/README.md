# CurvedInput

> **Category**: Chat AI & AI Agent Interfaces  
> **Source**: [https://reactbits.dev/](https://reactbits.dev/)

Arc-bent input bar with text, caret and submit button all following the curve.

---

## 📦 Arquivos Extraídos

| Arquivo | Descrição |
| --- | --- |
| `CurvedInput.tsx` | Componente pronto em React + TypeScript + Tailwind CSS |
| `CurvedInput.jsx` | Versão JavaScript + Tailwind |
| `CurvedInput.css` | Folha de estilos CSS puro auxiliar |
| `CurvedInputDemo.jsx` | Exemplo de uso prático e demo com estado |
| `registry.json` | Especificação completa shadcn / jsrepo com metadados |

---

## 🚀 Dependências Necessárias

```bash
npm install framer-motion lucide-react clsx tailwind-merge
```

---

## 💡 Como Usar

Veja o arquivo [`CurvedInputDemo.jsx`](./CurvedInputDemo.jsx) para o exemplo completo de implementação com estados, props e customizações.

```tsx
import CurvedInput from './CurvedInput';

export default function Example() {
  return (
    <div className="p-8 flex items-center justify-center">
      <CurvedInput />
    </div>
  );
}
```
